What Gets Opened

Bench one, what gets opened: analyze-pdf-metadata extracts and analyzes metadata from PDF files, flagging suspicious or unusual entries.

The inspection turns up, in the source's own terms: hidden document properties, creator information, and potential modification history that might indicate malicious intent or tampering. Its stated focus, data analysis and reporting, sits at the end of this panel as the bench's purpose tag.

Nothing about editing, repairing, or cleaning a PDF is claimed here, because the source describes an extractor and a flagger, not a workshop.

Coming Alongside

Installation is the single clone line as the source prints it, shown exactly in that spelling, with the wrong account name left visible on the page:

git clone https://github.com/ShadowStrikeHQ/analyze-pdf-metadata
./analyze-pdf-metadata [params]

This bench notes in its own text, not in small print, that the source gives no example PDF, no sample metadata listing, and no picture of what a flagged entry looks like, so a visitor learns the shape of the inspection but not yet its handwriting.
